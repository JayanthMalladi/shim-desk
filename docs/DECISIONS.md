## `npm test` is green on a fresh clone (01 §5.4, 2026-11-07)
Three causes, three fixes. **(a)** the r-0001 replay test in `test/ledger.test.mjs` drove `--auto-fixed-from` with the relative `work/r-0001/shim/report.json`; that flag is resolved against the CWD, so on a fresh clone (no gitignored `work/`) it ENOENTed. Now a committed fixture `test/fixtures/r-0001-report.json` holds the only field the flag reads (`autoFixed`), copied into the temp work dir, and passed as an **absolute** path — the test reads nothing from `work/`. **(b)** the root `test` script was bare `node --test`, which on Windows/Node 22 auto-discovers `ui/test/*.ts` (needs `ui/node_modules`) and whose dir form breaks — it is now `node --test "test/**/*.test.mjs"` (explicit root glob, cross-platform). **(c)** `ui/playwright.config.ts` webServer was `npm --prefix ui run dev -- …` — Playwright runs it with `cwd = ui/` (the config's dir), so `--prefix ui` resolved to `ui/ui/` → `ENOENT`, and `npm --prefix ui run e2e` only ever "passed" locally because a dev server was already on 5173 (`reuseExistingServer` picked it up). Now the in-dir form `npm run dev -- …`, so the e2e starts its own server on a clean clone.
